# Papi Mickey: Pasillos del Poder

Shooter retro de primera persona inspirado en los FPS de los 90. El protagonista es Papi Mickey y debe despejar un laberinto de enemigos caricaturizados.

Los retratos se generan con figuras geometricas dentro del programa. Los nombres de los enemigos son una parodia de figuras publicas chilenas y el juego no afirma representar sus rostros reales ni tiene afiliacion politica.

## Ejecutar

Desde esta carpeta:

```powershell
py -3 main.py
```

## Controles

- `W` / `S`: avanzar y retroceder
- `A` / `D`: desplazamiento lateral
- Flechas izquierda/derecha: girar
- `Espacio`: lanzar un disparo arcade
- `P`: pausar
- `R`: reiniciar

No requiere paquetes externos; utiliza Tkinter, incluido normalmente con Python para Windows.
